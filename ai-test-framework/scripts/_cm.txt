修复跨层参数 + 请求间隔防限流 + trace 平台分页

【生成器】_02_generate_dataset.py
- 跨层参数修复：一个能力含两个不同层级 ID 时（如 menu_bind_categories 的
  menuId 菜单 + categoryIds 分类），此前只按"第一个匹配层级"选一个实体，
  两个 ID 取成同一个值 → 服务端报错。新增 _layer_of_param() + _CURRENT_POOL，
  各 ID 参数从各自层级实体取值。

【执行器】generic_mcp_executor.py
- 新增 REQUEST_INTERVAL_MS（默认 0）：每次调用前可选 sleep，多轮采样
  （--runs>1）时用于避免触发服务端限流（PocketStore 5 次采样实测大量 429）。

【数据集】A/C_PocketStore 重新生成（应用上述跨层修复）。

【trace 平台】trace_platform/app.py
- 按批次点开 + 分页：/api/traces/batches 只返回批次摘要（去掉 1000 条上限、
  遍历全量统计）；新增 /api/traces/batch/{id}?offset=&limit=&filter= 分页拉明细，
  limit 硬上限 200 条/页。
- 前端：左侧批次点击才拉当前页；底部页码按钮（1 2 … cur … N，当前页高亮、
  省略号收敛）+ 自定义页码输入框，回车或点「跳转」跳页（越界自动夹取）。
- 键盘处理改用事件委托（只拦 Enter，Backspace/方向键放行），修复输入框
  无法退格/无法输入的问题。
